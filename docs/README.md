# Rheo Documentation Portal

This directory contains the Fumadocs documentation engine powering the official documentation for **Rheo**.

---

## Development

```bash
# Run local documentation server
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) to preview documentation changes in real-time.

---

## Structure

- `content/docs/`: MDX documentation pages covering overview, architecture, engine guides, and developer references.
- `lib/`: Fumadocs source adapter and layout configurations.
- `public/`: Static branding assets and icons.
